# Generated faces

`font_ui_14.c`, `font_ui_16.c`, `font_ui_20.c` and `font_ui_24.c` are generated by
`firmware/tools/make_fonts.py`. **Never edit them by hand**: the next run replaces
them.

One face per size, built from three sources:

- Montserrat Medium: ASCII, Latin-1 and Latin Extended-A (French through Polish),
  the bullet and the ellipsis, and the Cyrillic letters Russian needs;
- FontAwesome: LVGL's own symbol list, plus the few the settings menu draws;
- Noto Sans SC Medium: exactly the Han characters the translations use.

The character set is read from `main/i18n_table.h`, so adding a sentence and running
the script again is the whole procedure. The run ends by checking that every
character the table can draw has a glyph; LVGL draws a missing one as a blank box
and logs nothing.
