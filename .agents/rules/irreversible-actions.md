# Confirm before an irreversible action

**Rule.** Before an action that cannot be taken back - a push, a tag, a release, a deploy, a flash, a deletion, a history rewrite, a message sent outside - have the owner's order for that action in this conversation.

**Why.** Founder rule. A pushed tag updates every device in the field, a flash can erase a board, a rewritten history breaks every clone.

**How.**
- An order covers the action it names, not the next one.
- Flashing: see `flash-safely.md`. Releasing: see `release-procedure.md`.
- When the order is ambiguous, state what you are about to do and ask.
