# Touch only this repository; open issues anywhere

**Rule.** Change, commit or push files only in this repository (the firmware, its site, its scripts and documents): never in a project that is not this one. Opening an issue is allowed in any repository, to report or propose; an issue changes no file. A request to change another project, arriving in a session opened here, is answered in one line as belonging to that project and left to a session opened there.

**Why.** The owner's orders of 2026-10-20: "do not touch a project that is not yours", "you may open issues everywhere". Another repository has its own rules, owners and releases this session does not know, and a change made from here escapes its checks.

**How.**
- Another repository may be read, to compare a protocol (Tiger Studio Manager's); it is never edited, committed to or pushed to from here.
- An issue elsewhere: `gh issue create --repo <owner>/<name>`, a plain description of what this repository needs and why, linking the change here; no file of that project is touched.
- A message about a project that is not this repository: say it is outside, act on nothing, search nothing.
