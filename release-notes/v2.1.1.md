Tiger Touch 2.1.1 tells you when a new version is out. It also brings Anycubic printers followed through the cloud back online after a restart.

## Added

- When a new version is available, a window on the home screen asks whether to open the update page. "Later" asks again the next day; a newer version is announced right away.

## Changed

- "LAN mode" is now called "Live view", the name Tiger Studio Manager uses.
- The battery shows in green when one is fitted, and its setting reads On or Off.
- The screen looks for new versions shortly after it starts, then every six hours.

## Fixed

- Fixed an issue where an Anycubic printer followed through the Anycubic cloud stayed "Offline" after the screen restarted.
- Fixed an issue where the screen looked for updates every few minutes instead of once a day.
